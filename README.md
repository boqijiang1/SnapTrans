# SnapTrans · 翻译放大镜

一个小的玻璃态浮窗，浮在你想翻译的英文上，译文**按原排版原位覆盖**显示——哪句译文对应哪句原文一目了然。专为 ZCode 这类没有内置翻译的桌面客户端设计（插件介绍、AI 对话、说明文档等），其余界面完全不受影响。

## 快速上手

1. 首次使用：双击 `setup.bat` 安装依赖（只需一次，本机已装好可跳过）。
2. 以后启动：双击 `run.bat`。程序常驻系统托盘（右下角"译"字图标）。
3. 首次运行会弹出设置窗口：粘贴你在[智谱开放平台](https://open.bigmodel.cn)的 API Key（控制台 → API Keys），模型默认用免费的 GLM-4-Flash。
4. 按 `Ctrl+Alt+T` → 翻译放大镜出现在鼠标处，**自动翻译它覆盖的区域**。

## 放大镜怎么用

- **定位**：拖动顶部标题栏移动，浮窗近乎全透明，能直接看到下层内容；光标落下即定位
- **自动翻译**：移动或拉伸浮窗，停稳约半秒自动翻译新位置，不用点任何按钮（托盘菜单"移动后自动翻译"可关）
- **刷新**：按 `↻ 刷新` 重新翻译当前位置——浮窗没动但底下内容变了时用（滚动/切页后）
- **大小**：拖右下角拉伸，框住更多内容，松手自动翻译
- **悬停对照（默认）**：翻译完成后先显示原文，鼠标移到某句话上浮现双语气泡（小字原文+大字译文），**单击该行只复制该行译文**
- **替换模式**：按工具栏"悬停"按钮（或双击画布）切换，译文按原文的位置、字号、配色原位覆盖，适合通读整段；再按一次切回悬停
- **复制**：`⧉` 复制全部译文；`✕` 关闭；再按 `Ctrl+Alt+T` 随时唤出
- 显示模式会记住（存 config.json），下次启动保持你的习惯

## 翻译质量

- 界面短语用中文软件惯用译法（Copy→复制），说明文/介绍段落按专业、通顺标准翻译
- AI 术语按业界通用译法（prompt→提示词、plugin→插件、token→token）
- 代码、命令、变量名、路径、URL、占位符原样保留
- 行级缓存：相同文本只调一次 API，重复内容秒出
- 觉得 GLM-4-Flash 不够好，可在设置里换成 glm-4.5-flash（同样免费）

## 配置（config.json）

```json
{
  "api_key": "你的智谱 API Key",
  "model": "glm-4-flash",
  "hotkey": "ctrl+alt+t",
  "invert_threshold": 110
}
```

- `hotkey`：全局热键，支持 `ctrl / alt / shift / win` 组合或 `f1`~`f12`
- `invert_threshold`：截取区域灰度均值低于该值时先反色再 OCR（深色主题识别更准），一般不用改

## 已知限制

- 刷新是手动按（按你要求做的）；浮窗移动/调整大小后需要按 ↻ 才重新翻译
- 译文按 OCR 识别的文本块对位，极小字号或特殊字体的识别误差会影响贴片位置
- 翻译内容会上传给智谱 API，介意敏感信息的话避开即可

## 项目结构

```
snaptrans/
├── app.py             # 主控制器：热键、托盘、设置
├── lens.py            # 翻译放大镜：截图、译文原位贴片渲染
├── ocr_engine.py      # RapidOCR 封装（深底自动反色、按块整理坐标）
├── translator.py      # GLM 翻译客户端（编号协议 + 行级缓存）
├── settings_dialog.py # 设置窗口
├── glass.py           # 玻璃态：亚克力模糊 + QSS
└── config.py          # 配置读写
```
